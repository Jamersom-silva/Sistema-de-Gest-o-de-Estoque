# 📦 Sistema de Gestão de Estoque

O **Sistema de Gestão de Estoque** é um aplicativo Android desenvolvido em Java como projeto acadêmico durante o curso de **Análise e Desenvolvimento de Sistemas** na Universidade Estácio de Sá.

O projeto foi criado com o objetivo de aplicar conceitos de desenvolvimento mobile, arquitetura de software e persistência de dados, oferecendo uma solução para o gerenciamento de estoque. A aplicação permite cadastrar e organizar produtos, controlar quantidades, registrar datas de validade e armazenar IMEIs para rastreamento de dispositivos, proporcionando maior organização e controle das informações.

Além de seu propósito acadêmico, os conceitos e funcionalidades desenvolvidos neste projeto serviram como base para uma versão adaptada utilizada como ferramenta de apoio na organização de processos internos e controle operacional em ambiente de trabalho.

Este repositório contém a **versão demonstrativa** do sistema, desenvolvida para fins de estudo, prática e composição de portfólio.
